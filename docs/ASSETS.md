# Asset Requirements

This document tracks external visual assets that may be added after the initial frontend implementation.

## Phase 1 Rule

Do not block implementation on external imagery.

Prefer:

- CSS
- SVG
- typography
- gradients
- geometric elements
- icons
- charts
- data visualization
- UI composition
- animation

Use deliberate placeholders when an external visual asset would materially improve a section.

## Instructions

When the frontend identifies a useful external asset:

1. Add it to this document.
2. Describe why it is needed.
3. Specify the required aspect ratio.
4. Describe the subject and visual style.
5. Prefer sources with clear licensing terms.
6. Do not use AI-generated imagery.
7. Do not use random stock imagery merely to fill empty space.

Actual asset selection and integration can be completed in Phase 2.
